# 海洋 Minecraft Resources

這是「海洋」YouTube 頻道的官方 Minecraft 資源網站。

網站整理了每個系列、每部影片所使用的模組、Resource Pack、Shader、Datapack，以及各種建築與世界下載，方便觀眾查閱。

---

## 網站內容

- 首頁
- 生存世界系列
- 模組探索系列
- 每部影片專屬頁面
- Minecraft 資源整理
- 建築（Schematics）下載
- 更新紀錄

---

## 本機開發

安裝套件：

```bash
npm install
```

啟動開發伺服器：

```bash
npm run dev
```

網站網址：

```
http://localhost:4321
```

---

## 建置

```bash
npm run build
```

預覽：

```bash
npm run preview
```
